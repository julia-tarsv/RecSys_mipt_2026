Тарасова Юлия Игоревна

Датасет: UCI Online Retail (Daqing Chen, 2015), первоисточник, DOI:10.24432/C5BW33, лицензия CC BY 4.0.
https://archive.ics.uci.edu/dataset/352/online+retail

Задача: рекомендовать пользователю 10 товаров, которых он ещё не покупал. Считаем рекомендацию правильной, если пользователь впервые купил товар в будущем периоде.

Запуск: установить зависимости через pip install -r requirements.txt и выполнить ячейки по порядку. Файл Online Retail.xlsx загрузится с UCI автоматически. Если загрузка не сработает, скачать его со страницы датасета в data/Online Retail.xlsx
